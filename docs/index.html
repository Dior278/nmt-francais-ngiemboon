Le dépôt entraîne un petit modèle de traduction à partir de textes parallèles, puis propose une commande simple. Ce n’est pas un produit fini : une sortie se relit avec un locuteur.

python -m nmt.translate --dir fr2ng "Bonsoir, comment ça va ?"

L’autre sens existe aussi. On lui donne une vraie phrase ngiemboon, avec ses tons — pas un nom propre pris au hasard.
