English

A small program for French ↔ Ngiemboon and English ↔ Ngiemboon. English goes through French, because the network was trained on French–Ngiemboon sentences.

It is not reliable yet. Everyday sentences are missing. Check every result with a speaker. A tone changes the meaning: má is “mother”, mà is “robe”.

This page does not translate. Run the program on a computer:

python -m nmt --from en "Good evening"
python -m nmt --to en "má"
python -m nmt "Bonsoir"

Français

Un petit programme pour le français ↔ ngiemboon et l’anglais ↔ ngiemboon. L’anglais passe par le français, parce que le réseau a été entraîné sur des phrases français–ngiemboon.

Ce n’est pas encore fiable. Il manque des phrases de tous les jours. Une sortie se relit avec un locuteur. Un ton change le sens : má veut dire « mère », mà veut dire « boubou ».

Cette page ne traduit pas. Le programme se lance sur un ordinateur :

python -m nmt "Bonsoir, comment ça va ?"
python -m nmt --to fr "má"
python -m nmt --from en "Good evening"

Langue bamiléké des Grassfields, parlée à Batcham (Bamboutos, région de l’Ouest, Cameroun), aussi appelée guembon ou ngienboum. Écrite dans l’alphabet général des langues camerounaises.
