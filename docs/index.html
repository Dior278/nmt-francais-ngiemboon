Ngiemboon

guembon · ngienboum

Parlée à Batcham, dans les Bamboutos, à l’ouest du Cameroun. Écrite dans l’alphabet général des langues camerounaises.

Un ton change le sens. má veut dire « mère ». mà veut dire « boubou ».

Le modèle, aujourd’hui

Il ne traduit pas encore bien.

Il manque des phrases d’entraînement. Huit mille paires, surtout bibliques, ne suffisent pas pour la langue de tous les jours.

le pain → mbrɛ̀

Le modèle actuel ne produit pas ce mot de façon fiable. Une sortie se relit avec un locuteur.

Cette page n’héberge pas le réseau : c’est une page statique, et le modèle est un programme Python. Pour traduire vraiment, on lance le dépôt sur une machine.

python -m nmt.translate --dir fr2ng "Bonsoir, comment ça va ?"
